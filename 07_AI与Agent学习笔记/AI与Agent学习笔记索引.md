### Agent 进化六阶段（第12课精华）

```
Prompt Engineering（提示词工程）→ "戴着镣铐跳舞"
    ↓ 解决知识时效性
RAG（检索增强生成）→ "给大模型外挂一个U盘"（只读，不能干）
    ↓ 解决"不能干"
Function Calling（函数调用）→ "给大模型装上双手"（2023.6 OpenAI）
    ↓ 解决"单次指令"
Agent Loop（自主行动循环）→ ReAct（推理+行动）→ "从单次指令变成自主生物"
    ↓ 解决"能力不够多"
Skill（技能与插件）→ "AI的能力大爆发"
    ↓ 解决"工具太多无法工程化"
MCP（模型上下文协议）→ "建立Agent的USB-C接口标准"
```

### AI Agent vs 大模型 API 的三重本质区别

| 区别 | 大模型 API | AI Agent |
|---|---|---|
| 行动模式 | 单线（一问一答） | 循环闭环（思考-行动-观察 ReAct） |
| 工具调用 | 只输出文本建议 | 链式调用多个工具 |
| 记忆状态 | 实时失忆 | 持续记忆（上下文窗口保留） |

> **核心区别在于"自主"二字**：API 是"我问你答"，Agent 是"全权委托，闭环执行"。API 输出"文字建议"，Agent 输出"业务结果"。
