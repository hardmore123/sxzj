项目一　SmartResearch - 企业级多智能体深度研究系统 核心技术栈：Python, FastAPI, LangGraph, MCP, DeepSeek/Qwen, Milvus, Redis, PostgreSQL, Docker, SSE, asyncio 项目描述：面向企业对公场景的 Multi-Agent 深度调研系统，编排 6 个专家智能体构建"规划-检索-分析-写作-审核"闭环，将传统 3-5 天的行业研究压缩至 20-40 分钟，单次产出含 20-40 条去重信源、2-5 张图表的 3000-8000 字结构化研报。 认知编排与多智能体协作：以黑板模式（共享状态）驱动 6 个 Agent 协作，设计条件路由由审核 Agent 实现"通过/补充搜索/文字修订"三路智能决策；针对 LangGraph astream 仅支持节点级批量输出的局限，自研 asyncio.Queue 流式执行引擎，支持实时推送、阶段级检查点与随时取消；引入假设驱动机制（先立假设、检索时标注支持/反驳证据）强化长任务逻辑主线；混合模型策略（搜索用 Qwen-plus、推理写作用 DeepSeek）使单次成本较全量旗舰模型降低约 90%。 统一工具层与 MCP 服务化：将搜索、网页解析、向量检索、代码执行、可视化、股票查询等 6 类能力抽象为统一工具层（Tool 抽象+注册表+调用器），集中治理 Schema 校验/超时/重试/缓存/指标，进程内附加开销 ≤50ms，遵循开闭原则使新增工具零侵入；封装为标准 MCP Server（注册表元数据自动映射、stdio+网络双传输、Bearer Token 鉴权）供任意 MCP 客户端调用；以 Feature-Flag 灰度迁移保证行为等价、可回退，并沉淀 26 条正确性属性配合 Hypothesis 属性测试验证重构一致性。 混合 RAG 与长期记忆：整合 Milvus（IVF_FLAT/COSINE/1024维）与 DocMind 构建本地+全网混合检索，信源按 0-1 可信度分级、仅采纳 >0.6 事实；设计带重叠的分块策略平衡上下文完整性与检索精度；对话 Token 超 10K 自动触发记忆压缩，按摘要/洞察/主题多粒度独立向量化沉淀（压缩率约 96%），支撑跨会话语义召回。 长任务架构与状态恢复：基于 PostgreSQL+Redis 设计双写 Checkpoint（后端状态+前端UI状态，24h TTL），4 个关键阶段自动落盘支持断点续跑，避免已完成阶段的 LLM/搜索重复调用；结合 asyncio.Queue+SSE 推送 phase/action/search/chart/section 等 10+ 类进度事件，将分钟级黑盒等待转为秒级流式反馈。 安全沙箱与解析容错：代码执行工具采用两级安全模型——进程内正则黑名单+模块白名单静态拦截，MCP 暴露时追加子进程隔离与内存/CPU/网络资源限制（跨平台适配 setrlimit/Job Objects/监控降级），以进程隔离兜底静态检查的逃逸边界；针对 LLM 脏输出设计四级降级解析管道（代码块提取→括号截取→转义/尾逗号修复→字面量兜底），基于 200+ 条真实响应实测将解析成功率由约 62% 提升至约 97%、附加开销 <2ms，并支持代码执行失败 LLM 自愈（≤3 次）。

项目二：CertAgent · 企业级认证关键件清单智能比对与协同系统 核心技术栈：Python, LangGraph, DeepSeek V4, python-docx, PaddleOCR, OpenCC, Milvus, 飞书 Bitable OpenAPI, FastAPI, JWT, asyncio, React/TypeScript 项目描述：面向 CCC/CB 认证场景的多智能体清单比对与协同系统，基于 LangGraph 编排“识别—匹配—归纳—确认—分类—派单—审计—记忆”闭环，覆盖多机型、单份数百行的关键件清单，将人工核对从数小时压缩至分钟级，一键输出整合清单、变更对照表与跨专业任务派单。 · 认知编排与人在环协作：LangGraph StateGraph 构建 8 节点非线性工作流，以 interrupt/resume 实现差异确认挂起恢复、审计后条件边实现“通过/补录自愈”路由；单一 State 复用于图/顺序/Web 三种编排，判定 100% 可复现、可审计。 · 多模态识别与解析：文档侧用 python-docx 替代 Word COM 稳定解析含合并单元格的畸形认证表格(单表数百行、10 列)、OpenCC 繁简归一消除假差异，关键字段填充率≈100%；图像侧用 PaddleOCR 提取铭牌文字、pHash 判同一性、SSIM 定位变化区域，统一为结构化对象供下游比对。 · 确定性四层匹配引擎：针对结构化清单行设计“Rich 精确键→Loose 宽松键→型号集合→LLM 语义提名”分趟匹配，以分组为身份边界、多重集逐条消费，修复按名去重导致的整表 40%+ 行丢失缺陷，在千行级比对中实现行级对齐零丢行，并消除认证标准升版被静默判同的漏检。 · 组级语义归纳与反馈记忆：设计“关键件组”抽象将物理行按 7:1 聚合为业务动作，经 DeepSeek V4“条目数硬约束+全组覆盖自检”Prompt 将对照表业务模板覆盖率由 40% 提升至 100%、单次成本约 ¥0.008；构建“决策落盘→规则提炼→匹配回灌”反馈记忆闭环，以关键字精确匹配 + Milvus 向量语义召回双路检索历史决策/别名，解决命名多变导致的召回低问题，随使用积累规则、越用越准、模型依赖持续下降。 · 三层数据守恒审计：按引擎层、决策层、物理层回读 docx 三阶段正交校验，以行指纹多重集精确定位丢行并自动补录重审，实现批量比对信息零丢失，守恒等式实时可视化，满足认证合规“一行不错、一行不漏”。 · 飞书多维表格协同闭环：将差异按“变更类型×责任专业×处理动作×优先级”四维分类聚合为任务，经飞书 Bitable OpenAPI 幂等 upsert 写入、@责任人触发待办、附件挂 OCR 比对图并回写 record_id，打通“比对—分类—派单—跟踪”全链路。 · 异步全栈工程化：FastAPI + JWT + asyncio.Semaphore 构建异步任务服务，React/TypeScript 前端实现合并视图与 A|B 并排词级高亮，多层降级 JSON 解析保障脏输出下的服务稳定。
