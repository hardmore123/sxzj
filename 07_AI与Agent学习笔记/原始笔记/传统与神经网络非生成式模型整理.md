## 一、 传统与神经网络非生成式模型整理

按技术类型与发展演进，非生成式模型主要包含以下四类：

### 1. 传统编码标准与参考基准模型

- **AVS 系列（AVS1 / AVS2 / AVS3 / AVS4）**：中国自主音视频编解码标准，用于数字电视、4K/8K 超高清及全景视频的离散余弦变换与像素级冗余去除。
- **H.264x / H.265 / H.266**：国际主流传统混合视频编码标准体系。
- **HPM-15.1**：AVS3 的传统软件参考模型（Reference Software），用作新算法的性能对标基准。

### 2. 神经网络编解码工具模块（NN-based Coding Tools）

- **RLPP（基于强化学习的前处理）**：在编码输入端通过强化学习自适应优化图像质量。
- **NNIntra（神经网络帧内预测）**：利用卷积网络根据周围已重建像素推导未编码块。
- **VRF（虚拟参考帧生成模型）**：在帧间预测中合成高品质虚拟参考帧，提升预测精度。
- **NNLF / Transformer-based In-Loop Filter**：环路滤波器，用于去除变换量化产生的块效应与环影伪影。
- **FastFlowNet**：用于运动估计（ME）的光流提取网络，支持降采样计算以降低复杂度。
- **Boundary-aware deblocking network（边界感知去块网络）**：IEEE 1857.11 中的关键滤波技术，专注消除块边界伪影。
- **KNN Transformer Predictor / KNN & KNF 预测器**：基于 $K$ 近邻与 $K$ 近邻域（KNF）的轻量化预测器，通过组合双边网络、MLP 与自注意力机制实现无信号预测（Signal-free prediction）。

### 3. 端到端神经编解码模型（E2E Neural Codecs）

- **IEEE 1857.11 参考模型**：包含 Base / Main / High Profile 的端到端神经网络图像/视频编码标准模型。
- **AVS EEM (EEM 1.0 ~ 10.1 / EEMv9.2)**：AVS 官方端到端神经网络视频参考模型平台。
- **主流对比神经编解码器**：包含 MobileNVC、ELF-VC、C3、DHVC-2.0、DCVC-FM、DCVC-RT、DCVC 等端到端视频压缩模型。

### 4. 神经图像编码按架构分类发展史

- **基于 MLP（多层感知机）**：ICBP、CASCNN（早期低复杂度模型）。
- **基于 RNN（循环神经网络）**：ICRNN、RLVC、SAIC、HLVC（利用时序递归去除冗余）。
- **基于 VAE（变分自编码器）**：E2EIC、MSH、DeepCoder、DVC、SSF、GMLA、FVC、MLIC（当前主流自编码结构）。
- **基于隐式神经表示（Implicit Representation）**：COIN、NeRV、COOL-CHIC、MLSCN、D-NeRV（将图像/视频拟合为连续函数网络）。

### 5. 多模态与大语言模型（LLM）

- **SAM (ViTDet 80M)**：用于图像分割与局部 Patch 标记化的视觉基础模型。
- **CLIP (ViT 300M)**：用于提取高维视觉全局特征的编码器。
- **DeepSeek-3B (MoE-A570M)**：基于混合专家架构（MoE）的大语言模型解码器，负责将视觉特征转化为自然语言。

## 二、 生成式模型（Generative Models）单独整理

生成式模型旨在借助先验知识（Generative Priors）进行“条件生成与合成”，从传统的“像素重建”转向“语义与纹理生成”。

### 1. 模型列表与核心功能

| **模型/模块名称**                | **核心功能**                                                 |
| -------------------------------- | ------------------------------------------------------------ |
| **HiFiC / DiffEIC**              | 基于 GAN / 扩散过程的高保真生成式图像压缩模型。              |
| **AttnGAN**                      | 基于注意力机制的生成对抗网络，用于文本/语义驱动的图像生成。  |
| **LDM (Latent Diffusion Model)** | 潜在扩散模型，结合图像先验与 Prompt 优化，在极低码率下恢复高质感纹理。 |
| **VAE Encoder / Decoder**        | 变分自编码器，负责将视频时空条件映射至 Latent 空间并进行像素级解构重建。 |
| **ControlNet**                   | 条件控制网络，引导扩散过程精准符合原视频的时空结构约束。     |
| **Diffusion U-Net**              | 核心扩散去噪生成网络，利用高维先验从随机噪声中补偿极低码率丢失的细节与纹理。 |
| **Dual GAN / Side-info GAN**     | 基于双 GAN 的后处理增强网络，利用侧边信息消除解码画面伪影。  |
| **Generative Face Video Model**  | 人脸生成模型（包含解析模型与 Generator），利用紧凑参数驱动面部生成。 |

### 2. 生成式模型的评价指标 (Evaluation Metrics)

由于生成模型会“脑补”像素，传统 PSNR 指标表现可能较低，因此需依赖**主观与感知质量指标**及**分布拟合指标**：

- **感知与结构相似度指标**：
  - **DISTS (Deep Image Structure and Texture Similarity)**：衡量深度结构与纹理相似度（数值越低越好）。
  - **LPIPS (Learned Perceptual Image Patch Similarity)**：学习感知图像块相似度（数值越低表示视觉感知越接近）。
- **分布与真实感指标**：
  - **KID (Kernel Inception Distance)**：计算生成图像与真实图像特征分布的差异（数值越低表示画面越逼真）。
- **传输效率指标**：
  - **bpp** (bits per pixel) / **kbps** (千比特率)：衡量在超低带宽下的压缩极限。
- **生成优化理论目标函数**：
  - **重建优化目标**：$\min \mathbb{E}_{x \sim p_x}[-\log q(x\vert{}z)]$
  - **压缩优化目标**：$\min \mathbb{E}_{x \sim p_x}[-\log q(z\vert{}x)]$

### 3. 生成式模型的适用场景 (Applicable Scenarios)

- **超低码率极限传输（<50 kbps / 2~3 kbps 人脸视频）**：如偏远地区通信、卫星传输、弱网下的视频通话。
- **主观感知优先应用**：视频会议、安防监控流等对“绝对像素误差”不敏感但对“画面清晰自然度”要求较高的场景。
- **跨模态语义通信与存储**：仅传输文字 Prompt、边缘图（Edge Map）、深度图（Depth Map）或 2D/3D 关键点，在解码端实现最高 **1000×** 压缩率的图像还原。
- **数字人与面部视频驱动**：仅传输面部语义参数与关键点，在终端实时合成高保真面部视频。
