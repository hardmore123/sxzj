一、结果产出
端到端闭环跑通并可用：Word 两份清单 → 解析 → 四层匹配 → 组级归纳 → 人工确认 → 出【整合清单】+【变更前后对照表】，前后端全流程打通，单份数百行清单核对由数小时降至分钟级。
比对准确性达标：东芝真实样例差异分布 same 92 / changed 20 / only_plm 63 / only_orig 47，输出 222 行，数据守恒审计 222=222 零丢行；修复早期按名去重导致的整表 40%+ 行丢失缺陷（438→175）。
对照表归纳质量：组级抽象（205 行→43 组）+ DeepSeek V4 结构化 Prompt，业务模板覆盖率由 40%(2/5) 提升至 100%(5/5)，单次成本约 ¥0.008。
输出可直接交付：以输入文件为模板继承字体/字号/页面/列宽，来源转 Word 批注，变更字段词级黄色高亮，红字不加粗、表格带边框，产物可直接进认证流程。
测试全绿：smoke / test_audit / test_audit_fixes / test_review_order / test_writer_order / test_model_set_match / test_web_e2e 全部通过；完成多个版本快照归档。
扩展设计成文：输出《OCR 图片对比 + 网络信息库输入 + 飞书分类派单》正式设计文档。
二、具体工作
解析层

python-docx 替代 Word COM，根治 STA 单线程不稳定与批量卡死；.doc 经 LibreOffice/Word 子进程隔离自动转换。
处理横纵向合并单元格、分组标题、列偏移；OpenCC 繁→简归一消除繁简假差异。
匹配层

四层分趟匹配：Rich 精确键 → Loose 宽松键 → 型号集合关系 → 可选 LLM 语义提名；以分组为身份边界、多重集逐条消费。
修复贪心顺序错配 bug（逐行三级改分趟）；rich 命中后增加字段复核，消除"认证标准升版被静默判同"漏检。
归纳与记忆

关键件组抽象落 core；LLM 组级归纳接入 DeepSeek V4（Flash/Pro 对比）+ Prompt 硬约束。
反馈记忆：决策落盘 JSONL、别名挖掘 mine_aliases（带阈值）。
审计层

三层数据守恒审计（引擎/决策/物理回读）+ 行指纹多重集定位丢行 + 自动补录后重审；修复 4 个审计漏洞（含物理层不可读时假通过、指纹碰撞）。
Web 与输出

FastAPI + JWT + asyncio 异步任务服务；React 前端（登录/工作台/差异确认，合并视图 + A|B 并排词级高亮 + 审计面板）。
输出格式优化：来源批注、输入模板格式、词级高亮、边框修复，Web 链路同步生效。
