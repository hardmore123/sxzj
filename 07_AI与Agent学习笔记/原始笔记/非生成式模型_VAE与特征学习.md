------

# 一、非生成式模型（Non-Generative Models）

> 主要作用：
>
> 不直接生成图片，而是学习：
>
> - 图像特征
> - 风格表示
> - 内容结构
> - 参数变化规律

------

## 1. VAE Encoder / Decoder

| 项目     | 内容                                 |
| -------- | ------------------------------------ |
| 模型类型 | 变分自编码器                         |
| 核心功能 | 将图片映射到低维潜空间(latent space) |
| 输入     | 图片                                 |
| 输出     | latent向量                           |
| 项目作用 | 学习A、B之间的潜空间变化             |

------

### 在本项目中的作用

图片：
$$
A \rightarrow z_A
$$
图片：
$$
B \rightarrow z_B
$$
学习：
$$
\Delta z=z_B-z_A
$$
得到：

> 风格变化方向

------

### 适用场景

- 风格参数学习
- 图像压缩表示
- 图像编辑
- latent空间操作

------

# 2. CLIP

| 项目     | 内容                   |
| -------- | ---------------------- |
| 模型类型 | 视觉-语言联合表示模型  |
| 核心功能 | 提取图像语义和风格特征 |
| 输入     | 图片/文本              |
| 输出     | embedding向量          |

------

### 项目作用

学习：
$$
Style(B)-Style(A)
$$
例如：

A：

```
普通照片
```

B：

```
电影感照片
```

得到：

```
cinematic direction
```

------

### 适用场景

- 风格方向学习
- Prompt控制
- 生成模型约束
- 图像相似度评价

------

# 3. DINO / ViT

| 项目     | 内容             |
| -------- | ---------------- |
| 模型类型 | 视觉Transformer  |
| 核心功能 | 提取图像结构语义 |
| 特点     | 不依赖文本       |

------

### 项目作用

保证：

生成图片保持：

- 物体
- 几何结构
- 内容一致

例如：

输入：

汽车图片A

生成：

汽车图片B

DINO保证：

汽车仍然是同一辆。

------

### 适用场景

- 内容保持评价
- 特征匹配
- 图像检索

------

# 4. SAM

| 项目     | 内容         |
| -------- | ------------ |
| 模型类型 | 视觉基础模型 |
| 核心功能 | 图像分割     |

------

### 项目作用

进行区域级风格迁移：

例如：

```
天空 → 改变颜色
建筑 → 保持结构
人物 → 单独处理
```

流程：

```
图片
 |
SAM分割
 |
区域Style Transfer
```

------

### 适用场景

- 局部风格迁移
- 目标级编辑
- 图像增强

------

# 5. StyleGAN

| 项目     | 内容               |
| -------- | ------------------ |
| 模型类型 | GAN生成架构        |
| 核心功能 | 学习可解释风格空间 |
| 重点     | Style Vector       |

------

### 项目作用

学习：

哪些参数控制：

- 颜色
- 光照
- 纹理
- 人脸属性

例如：
$$
z_{style}
$$
对应：

```
+色调
+光照
+纹理
```

------

### 适用场景

- 参数变化学习
- 风格解耦
- 图像编辑

------

# 6. Implicit Neural Representation

代表：

- COIN
- NeRV
- COOL-CHIC
- D-NeRV

| 项目     | 内容           |
| -------- | -------------- |
| 模型类型 | 隐式神经表示   |
| 核心功能 | 用网络表示图片 |

------

### 项目作用

学习：
$$
Image=f_\theta(x)
$$
可以分析：

模型参数变化如何影响图像。

------

### 适用场景

- 参数化图像表示
- 神经渲染
- 视频表示

# 二、生成式模型（Generative Models）

> 目标：
>
> 学习：
> $$
> P(B|A)
> $$
> 即：
>
> 给定A，生成目标风格B。

------

# 1. Latent Diffusion Model (LDM)

| 项目     | 内容           |
| -------- | -------------- |
| 模型类型 | 扩散生成模型   |
| 核心功能 | 潜空间图像生成 |
| 输入     | 条件+噪声      |
| 输出     | 目标图片       |

------

### 工作流程

```
图片A

 ↓

VAE Encoder

 ↓

Latent

 ↓

Diffusion

 ↓

VAE Decoder

 ↓

图片B
```



------

### 适用场景

- 图像风格迁移
- 图像编辑
- 超低码率生成
- 艺术化转换

------

# 2. ControlNet

| 项目     | 内容             |
| -------- | ---------------- |
| 模型类型 | 条件扩散控制网络 |
| 核心功能 | 控制生成结构     |

------

### 项目作用

解决：

扩散模型容易改变内容的问题。

输入：

A：

- 边缘
- 深度
- 姿态
- 结构

输出：

B：

保持结构改变风格。

------

### 适用场景

- 精确图像编辑
- 风格迁移
- 姿态保持
- 工业设计

------

# 三、生成模型评价指标

生成模型不能只看PSNR。

------

# 1. 内容保持指标

## DINO Similarity

作用：

判断：

生成结果是否保持原内容。

越高越好。

适用：

A→B转换。

------

## LPIPS

作用：

衡量视觉感知距离。

越低越好。

适用：

图像生成质量评价。

------

# 2. 风格一致指标

## CLIP Similarity

作用：

判断：

生成结果是否符合目标风格。

越高越好。

------

## Gram Style Loss

作用：

衡量：

纹理统计一致性。

适合：

艺术风格迁移。

------

# 3. 图像真实性指标

## FID

作用：

衡量：

生成图片分布与真实图片分布距离。

越低越好。

适用：

GAN/Diffusion。

------

# 4. 像素指标

## PSNR

作用：

像素误差。

适合：

传统重建。

对于风格转换：

参考即可。

------

# 四、不同模型适用场景总结

| 任务                | 推荐模型                       |
| ------------------- | ------------------------------ |
| 学习A→B风格参数变化 | VAE + StyleGAN + CLIP          |
| 解释风格变化规律    | Implicit Representation + VAE  |
| 直接生成B           | LDM + ControlNet               |
| 有配对数据          | Pix2Pix                        |
| 无配对数据          | CycleGAN                       |
| 保持结构不变        | ControlNet + DINO              |
| 局部区域风格改变    | SAM + Diffusion                |
| 极低码率重建        | HiFiC/DiffEIC                  |
| 视频连续风格转换    | Video Diffusion + Optical Flow |



## 方案1：学习参数变化（解释性强）

```
A/B图片

 ↓

VAE Encoder

 ↓

latent_A / latent_B

 ↓

Style Mapper

 ↓

Δlatent

 ↓

生成B
```

模型：

- VAE
- StyleGAN
- CLIP
- Implicit Neural Representation

------

## 方案2：直接A→B转换（效果最佳）

```
图片A

 ↓

ControlNet

 ↓

Latent Diffusion

 ↓

图片B
```

模型：

- LDM
- ControlNet
- Diffusion U-Net
- VAE

评价：

- DINO（内容）
- CLIP（风格）
- LPIPS（感知）
- FID（真实性）
