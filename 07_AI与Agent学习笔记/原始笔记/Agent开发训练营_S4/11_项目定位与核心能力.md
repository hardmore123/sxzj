## 一、项目概述

### 1.1 项目定位

行业信息助手是一个 **多智能体协作的AI深度研究系统&#x20;**,专为行业分析师、投资研究人员、企业战略部门设计,能够自动完成从 **信息收集、数据分析到报告撰写&#x20;**&#x7684;完整研究流程。

**核心价值主张:**

<span style="color: rgb(36,91,219); background-color: inherit">• </span>将传统需要3-5天的行业研究工作压缩到30分钟内完成

<span style="color: rgb(36,91,219); background-color: inherit">• </span>通过多智能体协作保证研究的深度和质量

<span style="color: rgb(36,91,219); background-color: inherit">• </span>自动化的数据可视化和专业排版

<span style="color: rgb(36,91,219); background-color: inherit">• </span>可追溯的信息来源和可验证的数据

![](<images/1.1 项目定位与核心能力-26691785f2502e27780e74f9035a0e2a.png>)



### 1.2 应用场景

1\. **行业研究报告生成**

<span style="color: rgb(36,91,219); background-color: inherit">• </span>快速了解某个行业的市场规模、竞争格局、技术趋势

<span style="color: rgb(36,91,219); background-color: inherit">• </span>生成符合投行标准的深度研究报告

2\. **企业竞争分析**

<span style="color: rgb(36,91,219); background-color: inherit">• </span>分析特定企业的市场地位、业务模式、财务表现

<span style="color: rgb(36,91,219); background-color: inherit">• </span>横向对比多个竞争对手

3\. **政策影响评估**

<span style="color: rgb(36,91,219); background-color: inherit">• </span>追踪政策变化对行业的影响

<span style="color: rgb(36,91,219); background-color: inherit">• </span>预测政策趋势

4\. **技术趋势研判**

<span style="color: rgb(36,91,219); background-color: inherit">• </span>识别新兴技术的发展阶段

<span style="color: rgb(36,91,219); background-color: inherit">• </span>评估技术成熟度和商业化前景

### 2.4 双模式信息检索

**1. 网络搜索模式**

\- **搜索引擎&#x20;**: Bocha Web Search API

\- **深度阅读&#x20;**: 使用trafilatura提取网页正文

\- **递归搜索&#x20;**: 发现新线索自动深挖

\- **信源评级&#x20;**: 对来源进行可信度评分(0-1)

📍 **文件位置&#x20;**: \`/backend/app/service/deep\_research\_v2/agents/scout.py\` (行号: 1057-1122)

**评分标准&#x20;**:

<span style="color: rgb(36,91,219); background-color: inherit">• </span>官方来源(政府、央企): 0.9-1.0

<span style="color: rgb(36,91,219); background-color: inherit">• </span>学术来源(论文、研究机构): 0.8-0.95

<span style="color: rgb(36,91,219); background-color: inherit">• </span>权威媒体(央媒、财经媒体): 0.7-0.85

<span style="color: rgb(36,91,219); background-color: inherit">• </span>行业报告(券商、咨询): 0.7-0.9

<span style="color: rgb(36,91,219); background-color: inherit">• </span>一般新闻: 0.5-0.7

<span style="color: rgb(36,91,219); background-color: inherit">• </span>自媒体: 0.2-0.5



**2. 本地知识库模式**

\- **向量检索&#x20;**: 使用Milvus向量数据库

\- **语义搜索&#x20;**: 基于阿里text-embedding-v4模型

\- **文档解析&#x20;**: 支持PDF、Word、Excel等多种格式

\- **分块索引&#x20;**: 智能文档分块,保留上下文

📍 **文件位置&#x20;**: \`/backend/app/service/milvus\_service.py\`

### 3.2 信源追溯(Source Tracing)

<span style="color: rgb(36,91,219); background-color: inherit">• </span>chart: 图表生成

<span style="color: rgb(36,91,219); background-color: inherit">• </span>section\_content: 章节内容(流式显示)

<span style="color: rgb(36,91,219); background-color: inherit">• </span>report\_draft: 报告初稿

<span style="color: rgb(36,91,219); background-color: inherit">• </span>checkpoint\_saved: 检查点保存成功

## 七、常见问题

**Q1: 为什么使用多智能体而不是单一Agent?**

A: 单一Agent容易陷入"万能助手"的陷阱,无法在每个任务上做到专业。多智能体分工协作,每个Agent可以优化自己的Prompt和模型,提升整体质量。



**Q2: 生成的报告可信度如何保证?**

A: 三层保障机制:

**<span style="color: rgb(36,91,219); background-color: inherit">1. </span>**&#x4FE1;源评级系统(只采纳可信度>0.6的事实)

**<span style="color: rgb(36,91,219); background-color: inherit">2. </span>**&#x43;riticMaster对抗式审核(发现幻觉和矛盾)

**<span style="color: rgb(36,91,219); background-color: inherit">3. </span>**&#x5B8C;整的引用链(用户可追溯每个数据来源)



**Q3: 能否支持垂直领域定制?**

A: 可以。通过以下方式定制:

**<span style="color: rgb(36,91,219); background-color: inherit">1. </span>调整Agent的Prompt模板(针对特定行业，加入行业的knowhow)**

**<span style="color: rgb(36,91,219); background-color: inherit">2. </span>**&#x914D;置领域知识库(导入行业专业文档)

**<span style="color: rgb(36,91,219); background-color: inherit">3. </span>**&#x8BBE;置搜索偏好(优先级、来源白名单)



**Q4: 与ChatGPT、Claude等通用LLM有何区别?**

A: 通用LLM擅长对话和知识问答,但难以完成系统性的深度研究。本项目的优势:

<span style="color: rgb(36,91,219); background-color: inherit">• </span>自动搜索和信息收集

<span style="color: rgb(36,91,219); background-color: inherit">• </span>结构化的数据提取和分析

<span style="color: rgb(36,91,219); background-color: inherit">• </span>专业的报告排版和引用

<span style="color: rgb(36,91,219); background-color: inherit">• </span>可验证的信息来源
