## **AI Agent工程师需要什么能力？**

#### **<span style="color: rgb(36,91,219); background-color: inherit">1. Agent组件设计和系统编排</span>**

* **核心模块开发：&#x20;**&#x6784;建并优化Agent的关键组件，包括 **<span style="color: rgb(216,57,49); background-color: inherit">记忆 (Memory)、规划器 (Planner) 和工具调用 (Function Call/Tool Use) </span>**&#x7B49;。

* **核心决策workflow：&#x20;**&#x5B9E;现并优化 **“规划 (Plan) -> 行动 (Action) -> 反思 (Reflect)&#x20;**”的自主决策循环。

* **Prompt工程：&#x20;**&#x7F16;排和优化指令，引导模型完成复杂的推理和执行任务。

#### **<span style="color: rgb(36,91,219); background-color: inherit">2. Agent后端服务和工程化</span>**

* **模型API集成：&#x20;**&#x90E8;署主流模型服务接口（如 OpenAI API），实现高效、可靠的模型调用。

* **后端服务：&#x20;**&#x6784;建 Agent **<u><span style="color: rgb(216,57,49); background-color: inherit">服务端组件、API 接口、持久化层、缓存层、任务调度与并发控制、监控与日志体系等 （openai接口、redis、docker微服务架构）</span></u>**

* **工程化落地：&#x20;**&#x90E8;署、监控、调优 Agent 在生产环境中的稳定性与性能；版本迭代、异常处理等

#### **<span style="color: rgb(36,91,219); background-color: inherit">3. LLM模型训练</span>**

* **指令微调（SFT）：&#x20;**&#x6839; **<span style="color: rgb(216,57,49); background-color: inherit">据垂直领域的专有语料数据，对基础大模型进行指令微调 </span>**，使模型更好地理解和执行特定场景下的任务。

* **偏好对齐与强化学习（可选）：&#x20;**&#x5E94;用RLHF（人类反馈强化学习）、DPO（直接偏好优化）以及PPO等技术对模型进行微调，提升模型在特定任务上的表现，使其输出更符合人类预期。

* **前沿技术探索 (Deep Research、AgentRL等)：&#x20;**&#x6301;续跟进并研究最新的Agent理论与模型架构，并将其转化为工程应用。

*

#### **<span style="color: rgb(36,91,219); background-color: inherit">4. Agent自动化数据流</span>**

* **数据链路构建 <span style="color: rgb(216,57,49); background-color: inherit">DataAgent </span>：&#x20;**&#x8BBE;计并实现完整的数据处理管道，为Agent提供动态信息输入。

* **检索增强生成 (RAG)：&#x20;**&#x6784;建并优化RAG系统，通过 **Embedding&#x20;**&#x548C; **向量数据库 (如 Milvus）&#x20;**&#x4E3A;Agent注入外部知识。

### 第一周：Agent的知识核心 (向量数据库 & RAG)

* **学习目标：&#x20;**&#x4E3A;Agent构建 **<span style="color: rgb(36,91,219); background-color: inherit">“感官” </span>**&#x548C;“ **<span style="color: rgb(36,91,219); background-color: inherit">长期记忆 </span>**”系统。这是所有智能决策的数据基础，是Agent的“图书馆”和知识沉淀体系。 **<span style="color: rgb(36,91,219); background-color: inherit">从传统RAG到DataAgent和长期记忆</span>**

* **核心理论：**

  * **Agent知识系统导论&#x20;**：深入理解为何RAG (检索增强生成) 是构建可信、可控Agent的基石。

  * **Embedding与向量数据库&#x20;**：学习主流文本向量化模型（如BGE, M3E）的原理与选型，并深入掌握 **<span style="color: rgb(36,91,219); background-color: inherit">Milvus </span>**&#x5411;量数据库的核心架构与使用方法。

* **工程实践：**

  * **Lab 1：构建工业级RAG知识库管道**

    * 实现对非结构化数据的清洗、去重、多粒度切块策略。

    * 调用Embedding模型将文本块向量化，并存入Milvus。

    * 设计并实现知识库的增量更新与过期淘汰机制，确保知识的时效性。

* **本周产出：&#x20;**&#x4E00;个功能完备、可持续更新的自动化知识处理管道。

### 第二周：DeepResearch核心 —— 决策循环与基础工具 (Core Logic & Basic Tools)

[ 第二周：DeepResearch核心 —— 决策循环与基础工具 (Core Logic & Basic Tools)](https://my.feishu.cn/wiki/ComRws5oFiCF8ektfaxcK9MTnMb)

* **学习目标：&#x20;**&#x5F00;发Agent的核心“大脑”，实现智能决策与执行的核心逻辑，并集成基础的信息获取工具。

* **核心理论：**

  * **<span style="color: rgb(36,91,219); background-color: inherit">ReAct决策模型 </span>**：深入理解“规划 (Plan) -> 行动 (Action) -> 反思 (Reflect)”的自主决策循环，这是Agent智能的源泉。

  * **<span style="color: rgb(36,91,219); background-color: inherit">Function Calling/Tool Use </span>**：学习如何通过精心设计的Prompt和模型能力，让LLM理解并调用外部工具。

  * **<span style="color: rgb(36,91,219); background-color: inherit">Agent记忆机制 </span>**：学习短期记忆与长期记忆的设计理念。

* **工程实践：**

  * **Lab 1：实现Agent的ReAct决策引擎**

    * 开发 **任务规划器 (Planner)&#x20;**，接收用户复杂问题，并调用LLM生成结构化的多步骤执行计划。

    * 开发 **工具调用器 (Executor)&#x20;**&#x548C; **反思器 (Reflector)&#x20;**，形成Plan -> Act -> Reflect的闭环。

  * **Lab 2：集成信息检索工具与短期记忆**

    * 将第一周构建的RAG知识库封装成Agent可调用的工具。

    * 集成Web Search工具，赋予Agent获取实时信息的能力。

    * **实现需求&#x20;**：使用Redis实现短期记忆模块，存储当前对话的上下文和任务执行的中间步骤。

  * **Lab 3：数据采集Agent (DataAgent)**

    * 开发一个可配置的Web抓取器，通过定时任务持续从指定的行业网站（如财经新闻、政策发布平台）采集最新信息。

    * 实现一个API数据对接器，连接外部金融数据API，将结构化信息源源不断地输入系统。

* **本周产出：&#x20;**&#x4E00;个具备初步智能、能够结合内外知识回答问题的单体Agent。

### 第四周：Agent进阶 —— 多智能体协作与长期记忆 (Multi-Agent & Memory)

**学习目标：&#x20;**&#x4ECE;单体智能走向群体智能，学习如何设计和编排多个专业Agent协同工作，并完善其长期记忆机制。

* **核心理论：**

  * **多智能体系统 (Multi-Agent System)&#x20;**：学习其设计模式，如分层结构、协作模型等，理解“分而治之”的优势。

  * **MCP (Model Context Protocol)&#x20;**：学习MCP作为一种通用的Agent间通信与工具调用协议，实现系统的解耦和可扩展性。

* **工程实践：**

  * **Lab 1：构建基于MCP的多智能体系统**

    * **实现需求&#x20;**：将系统重构为微服务架构的MCP Server和多个MCP Client。

    * 定义不同角色的Agent：如“总控Agent”、“数据检索Agent”、“数据分析Agent”。

    * 将所有工具（RAG, Web Search, Text2SQL, Code Interpreter等）全部封装为可独立调用的MCP客户端。

  * **Lab 2：实现高级长期记忆机制**

    * **实现需求&#x20;**：设计并实现Agent的长期记忆模块。当短期记忆（如对话历史）达到一定长度（例如10000个token）时，自动触发一次总结，将核心洞察和知识点压缩后，存入Milvus向量数据库，并用总结更新短期记忆。

* **本周产出：&#x20;**&#x4E00;个模块化、可扩展、具备长期学习能力的多智能体协作系统。
