### 3.2 run\_agent\_with\_streaming - Agent 流式执行

```python
async def run_agent_with_streaming(agent):
    """执行 agent 并实时 yield 消息"""
    # 检查是否已取消
    if await check_cancelled():
        logger.info(f"Research cancelled before starting agent: {agent.name}")
        return

    logger.info(f"Starting agent: {agent.name}")

    # 启动 agent 处理任务
    task = asyncio.create_task(agent.process(state))

    msg_count = 0
    # 在任务执行期间持续从队列获取消息
    while not task.done():
        # 定期检查是否已取消
        if await check_cancelled():
            logger.info(f"Research cancelled during agent: {agent.name}")
            task.cancel()
            try:
                await task
            except asyncio.CancelledError:
                pass
            return

        try:
            # 非阻塞获取消息，超时 0.5 秒
            msg = await asyncio.wait_for(message_queue.get(), timeout=0.5)
            msg_count += 1
            yield msg
        except asyncio.TimeoutError:
            # 继续等待，不发送心跳
            continue

    # 等待任务完成
    try:
        await task
    except Exception as e:
        logger.error(f"Agent {agent.name} error: {e}")

    # 清空剩余的消息
    while not message_queue.empty():
        msg = message_queue.get_nowait()
        yield msg
```

**设计亮点&#x20;**:

1. **异步任务&#x20;**: 使用 `asyncio.create_task` 创建 agent 处理任务

2. **非阻塞轮询&#x20;**: `wait_for(timeout=0.5)` 避免永久等待

3) **取消检测&#x20;**: 任务执行期间定期检查取消标志

4) **双重清空&#x20;**: 任务完成后再次清空队列，确保消息不丢失

### 3.4 save\_checkpoint\_async - 异步保存检查点

```python
async def save_checkpoint_async(step_info: dict = None):
    """异步保存检查点"""
    # 更新 UI 状态
    update_ui_state()
    
    # 添加研究步骤
    if step_info:
        existing = next(
            (s for s in ui_state["research_steps"] if s.get("type") == step_info.get("type")),
            None
        )
        if existing:
            existing.update(step_info)
        else:
            ui_state["research_steps"].append(step_info)

    # 保存检查点
    if self._save_checkpoint(state, user_id, ui_state):
        return {"type": "checkpoint_saved", "phase": state.get("phase", ""), "session_id": session_id}
    return None
```

## 总结

1. **异步队列通信&#x20;**: 使用 `asyncio.Queue` 实现 Agent 与主流程的解耦

2. **非阻塞轮询&#x20;**: 0.5 秒超时避免永久等待，保持响应性

3) **取消检测&#x20;**: 每个阶段开始前和执行中都检查取消标志

4) **检查点保存&#x20;**: 每个阶段完成后保存状态，支持断点恢复

5. **智能路由&#x20;**: 审核后根据结果决定补充搜索还是直接修订

6. **错误处理&#x20;**: 完善的 try/except/finally 结构确保资源清理

### 核心问题

Agent（如 DeepScout）在执行搜索时，会**持续产生消息**（搜索进度、搜索结果等），这些消息需要**实时发送给前端**，而不是等 Agent 执行完才一次性返回。

### 数据流向
```
┌─────────────────┐          ┌─────────────────┐          ┌─────────────────┐
│   Agent         │          │  message_queue  │          │   主流程        │
│  (DeepScout)    │  ──put──>│  (asyncio.Queue)│  ──get──>│  (yield SSE)    │
│                 │          │                 │          │                 │
│ 搜索中...       │          │ [msg1, msg2...] │          │  发送给前端     │
└─────────────────┘          └─────────────────┘          └─────────────────┘
     生产者                       缓冲区                       消费者
````
