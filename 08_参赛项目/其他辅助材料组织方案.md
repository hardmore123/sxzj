### 二、各目录详细内容说明

#### 01_可执行程序/

**目的**：证明项目已完成核心功能开发，具备可运行、可演示的交付状态。

**建议包含内容**：

| 文件/目录               | 说明                             | 来源/准备方式                                                |
| :---------------------- | :------------------------------- | :----------------------------------------------------------- |
| `HiMate_Agent_Runtime/` | Agent运行时核心可执行文件/部署包 | 从当前部署环境（10.18.87.44:9001）打包                       |
| `skills/`               | 已集成的三条业务线Skill完整目录  | 从部署环境中导出 `skills/finance/`、`skills/sap/`、`skills/defect/` |
| `deploy/`               | 一键部署脚本（`start.sh`等）     | 从 `bin/` 目录提取                                           |
| `README.md`             | 快速启动说明                     | 新建，包含部署步骤和访问方式                                 |
| `requirements.txt`      | 依赖清单                         | 从项目环境中导出 `pip freeze > requirements.txt`             |

**关键说明**：

- 可执行程序不要求是编译好的二进制文件，**Python源码+启动脚本**同样符合“可执行程序”的定义；
- 如果代码涉及公司内部敏感信息（如内网IP、API密钥），建议做**脱敏处理**，替换为示例配置；
- 评审专家关注的是**能否运行**，建议在压缩包中附带一个最小化的演示数据集或Mock后端服务。

#### 02_项目代码/

**目的**：展示完整的代码实现，证明项目为团队自主开发，具备工程化水平。

**建议包含内容**：

| 文件/目录                | 说明                                               | 来源/准备方式                     |
| :----------------------- | :------------------------------------------------- | :-------------------------------- |
| `src/`                   | 核心源代码目录                                     | 从Git仓库导出                     |
| `src/core/`              | Agent运行时核心（tool、message、permission等模块） | 项目源码                          |
| `src/tools/`             | Custom Tool实现（含已实现的工具）                  | 项目源码                          |
| `config/`                | 配置文件（agents/lead/config.yaml等）              | 项目源码                          |
| `tests/`                 | 单元测试与集成测试用例                             | 新建或补充                        |
| `.git/` 或 `git_log.txt` | Git提交记录（可选）                                | `git log --oneline > git_log.txt` |

**关键说明**：

- 提交代码时建议包含**适量的代码注释**（尤其是核心模块），体现工程规范性；
- 可附带**Git提交记录截图**或日志，证明代码是在参赛周期内逐步完成的，而非临时拼凑【6†L1-L7】；
- 代码规模建议控制在**合理范围**（核心模块完整即可），无需包含所有第三方依赖库。

#### 03_技术文档/

**目的**：提供辅助理解项目的详细文档，与主项目文档形成互补。

**建议包含内容**：

| 文档名称               | 内容说明                                                     | 篇幅建议 |
| :--------------------- | :----------------------------------------------------------- | :------- |
| `系统架构设计文档.pdf` | 详细的分层架构说明、模块划分、接口定义、数据流向             | 10-20页  |
| `开发者接入指南.pdf`   | 三种对接方式（Skill/Custom Tool/MCP）的详细接入步骤与代码示例 | 15-25页  |
| `API接口文档.pdf`      | Agent运行时对外提供的API接口规范（请求/响应格式、错误码）    | 5-10页   |
| `部署运维手册.pdf`     | 环境要求、部署步骤、配置说明、日志查看、常见问题排查         | 5-8页    |

**关键说明**：

- 这些文档**不要求全部从头撰写**，可以将项目开发过程中积累的设计文档、接口说明整理成册；
- 开发者接入指南可重点参考你提供的HiMate系统说明PDF中第3-11页的内容，扩展为完整文档【1†L1-L4】；
- 文档格式统一为PDF，命名规范清晰。

#### 04_演示与验证/

**目的**：提供可视化的证据，证明系统真实可用且效果可验证。

**建议包含内容**：

| 文件/目录            | 说明                                 | 准备方式                                  |
| :------------------- | :----------------------------------- | :---------------------------------------- |
| `系统运行录屏.mp4`   | 3-5分钟的系统全流程演示视频          | 屏幕录制软件（OBS等）                     |
| `业务场景演示截图/`  | 三个业务Skill的对话界面截图          | 从PDF第11-12页提取或重新截取【1†L11-L12】 |
| `性能测试报告.pdf`   | 推理延迟、并发能力等测试数据与结论   | 整理测试日志                              |
| `数据流向示意图.pdf` | 从用户提问到后端服务调用的完整数据流 | 用[Draw.io](https://draw.io/)绘制         |

**运行录屏建议脚本**（3-5分钟）：

| 时间段    | 内容                                                         |
| :-------- | :----------------------------------------------------------- |
| 0:00-0:30 | 打开浏览器访问 `http://10.18.87.44:9001/`，展示登录后的主界面 |
| 0:30-1:30 | **财务政策查询**：输入“研发费用怎么归集？”→ 展示Agent调用Skill→返回结构化结果 |
| 1:30-2:30 | **SAP物料维护**：输入“查询物料XX的库存信息”→ 展示Agent调用SAP Skill→返回结果 |
| 2:30-3:30 | **缺陷分析**：输入“分析最近一周的缺陷趋势”→ 展示Agent返回分析报告 |
| 3:30-4:00 | 展示**热加载能力**：将一个新的Skill目录放入`skills/`→无需重启即可调用 |
| 4:00-5:00 | 总结：展示系统架构图，点明三层能力注入机制                   |

**关键说明**：

- 录屏无需专业剪辑，**清晰展示操作过程和系统响应即可**；
- 建议在录屏中**同时展示代码编辑器和浏览器**（分屏），证明是真实系统运行而非PPT演示；
- 如果系统涉及内部敏感数据，演示时使用脱敏后的示例数据。

#### 05_支撑材料/

**目的**：提供数据来源、引用声明、团队信息等辅助证明。

**建议包含内容**：

| 文件名称                         | 内容说明                                                     |

| `数据来源说明.pdf`               | 详细说明财务政策数据、SAP物料数据、缺陷数据的来源、获取方式、脱敏处理情况【1†L1-L10】 |
| `引用与借鉴声明.pdf`             | 逐项列出引用的开源框架、协议规范、第三方库及其使用方式【1†L1-L7】 |

| `专利_软著_获奖证明.pdf`（如有） | 已申请或已获得的专利受理书、软件著作权证书等                 |
