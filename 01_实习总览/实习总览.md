## 二、两个核心项目

### 项目一：认证智能体 CertAgent（已上线）

| 项 | 内容 |
|---|---|
| **做什么** | 两份 Word 关键件清单自动解析 → 差异识别 → AI 归纳 → 人工确认 → 生成整合清单+对照表 |
| **技术栈** | FastAPI + React/Vite + LangGraph + python-docx + SQLite |
| **生产地址** | http://10.18.87.51/certagent/ |
| **代码仓库** | GitLab: `Full-Stack-Frontend/Hisense/Agents/AI_Applications/CertAgent.git` |
| **状态** | ✅ 已上线、已上传 GitLab |
| **桌面位置** | `桌面\项目\CertAgent\`（部署版）、`桌面\项目\list-merge-demo\`（开发版） |

**核心价值**：把"人工逐行比对 Word 表格"变成"机器解析比对 + AI 辅助归纳 + 人工确认 + 自动生成文档"的闭环，并沉淀每次确认经验供后续任务复用。

### 项目二：海外电视数据爬取（已交付）

| 项 | 内容 |
|---|---|
| **做什么** | 自主搜索产品，采集**价格 / 评价 / 规格**，按时序入库，产出周度报表与竞品对阵分析 |
| **技术栈** | Python + Playwright + SQLite + LangGraph + Crawl4AI（借鉴） |
| **规模** | 260 站点 / 13,507 产品 / 146,853 规格行 / 84,095 评价 |
| **部署包** | v3.0（81.8MB，排除 browser_profile） |
| **桌面位置** | `桌面\爬取项目\`、`桌面\爬取项目\海外数据爬取_部署包\` |

**核心方法论**：`① agent+skill 探索一次 → ② 引擎读配置长期复用 → ③ 经验回灌 skill` 的闭环，让接站成本随接站数量递减，日常重跑 LLM 成本为 0。

### 子项目：竞品上市预警系统

| 项 | 内容 |
|---|---|
| **做什么** | 自动抓取全球7个权威认证数据库（FCC/EPREL/ENERGY STAR/ANATEL/IC-ISED/TÜV/VDE-CB），监控6家竞品新品认证动态，提前生成上市预警信号 |
| **规模** | 851条记录 / 129条上市预警 / ~5000行代码 |
| **亮点** | FCC最提前211天预警、子品牌识别、LLM解读、Web看板（端口8088） |
| **桌面位置** | `桌面\爬取项目\预警相关抓取功能\` |
