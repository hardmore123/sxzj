## 1. 项目概述

### 1.1 系统定位

本系统是一个**多数据源 × 多竞品品牌**的上市预警平台：
- 自动抓取全球 7 个权威认证数据库的公开数据
- 监控 6 家电视/显示器竞品品牌的新品认证动态
- 生成上市预警信号并可视化呈现
- 竞品新品在认证时即被发现，比官方发布/电商上架提前数周到数月

### 1.2 核心指标

| 指标 | 数值 |
|------|------|
| 数据源 | 7 个（FCC/EPREL/ENERGY STAR/ANATEL/IC-ISED/TÜV/VDE-CB） |
| 竞品品牌 | 6 家（Samsung/LG/Hisense/TCL/Sony/Panasonic） |
| 总记录 | 851 条（全部近1年认证） |
| 总信号 | 980 条 |
| 上市预警 | 129 条 |
| 代码量 | ~5000 行 Python + 347 行 HTML |
| 数据库大小 | 25MB（SQLite） |

## 3. 数据库设计

数据库为 SQLite（`data/overseas.db`），共 10 张表，其中 6 张为核心表。

### 3.1 `compintel_record`（认证记录表，851 行）

存储各数据源抓取的认证记录。每条记录 = 一个 source_id 在某个数据源的认证。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| run_id | INTEGER | 抓取批次 ID（关联 crawl_run） |
| source | TEXT NOT NULL | 数据源：fcc/eprel/energystar/anatel/ic_ised/tuv/ul |
| source_id | TEXT NOT NULL | 认证 ID/注册号（如 FCC ID、EPREL 注册号） |
| product_group | TEXT | 产品组（EPREL: electronicdisplays/televisions） |
| applicant | TEXT | 申请人/供应商名 |
| applicant_code | TEXT | 授权码（FCC Grantee Code） |
| brand | TEXT | 竞品品牌名（标准化后） |
| model | TEXT | 型号 |
| description | TEXT | 产品描述 |
| auth_date | TEXT | 认证日期（YYYY-MM-DD） |
| market_start | TEXT | 上市开始日期（EPREL 专用） |
| market_end | TEXT | 上市结束日期（EPREL 专用） |
| frequency | TEXT | 频率范围（FCC 专用） |
| energy_class | TEXT | 能效等级（EPREL/ES: A~G） |
| extra_json | TEXT | 额外字段 JSON（规格参数等） |
| confidentiality | TEXT | 保密状态（FCC 专用） |
| captured_at | TEXT NOT NULL | 入库时间戳 |

**UNIQUE 约束**：`(source, source_id, captured_at)` — 同一 source_id 可在不同时间多次入库。
**索引**：source+auth_date、source+source_id、brand+model、source+applicant。

> ⚠️ **设计注意**：UNIQUE 含 captured_at 导致同 source_id 可重复入库。`add_record()` 已在 INSERT 前查重修复此问题。

### 3.2 `compintel_alert`（预警信号表，980 行）

存储所有检测到的信号。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| run_id | INTEGER | 检测批次 ID |
| signal_type | TEXT NOT NULL | new_fcc_id / new_cert / eprel_new_reg / launch_warning |
| source | TEXT NOT NULL | 数据源 |
| applicant | TEXT | 申请人 |
| brand | TEXT | 竞品品牌 |
| model | TEXT | 型号 |
| source_id | TEXT | 关联的认证 ID |
| level | TEXT NOT NULL | 级别：info/warn/alert |
| message | TEXT NOT NULL | 信号描述消息 |
| details_json | TEXT | 详细信息 JSON（product_type/lead_days/on_market等） |
| detected_at | TEXT NOT NULL | 检测时间戳 |

**UNIQUE 约束**：`(signal_type, source, source_id, detected_at)`。

### 3.3 其他表

| 表名 | 行数 | 说明 |
|------|------|------|
| `crawl_run` | 206 | 抓取批次记录（scenario/status/ok_count/fail_count） |
| `compintel_crawl_state` | 85 | 各数据源抓取断点状态 |
| `crawl_error` | 1175 | 抓取错误日志 |
| `compintel_doc` | 0 | 认证文档（FCC 内部照片/测试报告链接） |
| `compintel_skip` | 0 | 跳过的 source_id 记录 |
| `product` | 1015 | 海外采集框架产品表，用于判断"是否已在售" |
| `product_spec` | 15 | 产品规格 |

### 3.4 数据流向

```
爬虫(fcc_crawler/eprel_crawler/...)
    ↓ 抓取认证记录
orchestrator.py
    ↓ 调 compintel_db.add_record() 入库
compintel_record 表
    ↓ 调 alert.detect_new_records() / detect_launch_warning()
compintel_alert 表
    ↓ Web API 查询
dashboard.html 前端展示
```

## 7. 已知问题与限制

### 7.1 数据源 API 限制（不可修复）

| 数据源 | 限制 | 影响 |
|--------|------|------|
| **EPREL** | offset 翻页不工作，只能取最新 25 条/品牌 | 只能抓到每个供应商的最新 25 条 |
| **TÜV Certipedia** | 搜索页无结构化 model/auth_date | TÜV 89 条记录的 model 和 auth_date 全空 |
| **VDE Solr** | API 不返回认证日期 | VDE 136 条记录的 auth_date 全空 |
| **IC/ISED** | API 不稳定，频繁 HTTP 500 | 部分公司号抓取失败，近1年仅 2 条 |
| **ANATEL** | 全量 ZIP-CSV 53MB，电视类占比极低 | 223 条中只有 1 条 launch_warning |

### 7.2 代码层面问题

| 问题 | 位置 | 严重程度 | 说明 |
|------|------|----------|------|
| UNIQUE 含 captured_at | compintel_record 表 | 低 | `add_record` 已加查重修复 |
| 5 个信号函数未启用 | orchestrator.py | 中 | 已实现但未调用 |
| TÜV launch_warning 0 条 | alert.py | 低 | description 无电视关键词 |
| LLM 依赖内网 | llm_analyze.py | 中 | 外部部署需替换模型配置 |
| Web 无守护进程 | web_api.py | 中 | 生产环境需配 systemd/supervisor |

### 7.3 数据覆盖缺口

| 品牌 × 数据源 | 状态 | 说明 |
|---------------|------|------|
| Samsung × EPREL | 0 条 | 近1年无新电子显示器注册（API 确认） |
| Hisense × EPREL | 0 条 | 近1年无新注册 |
| TCL × EPREL | 0 条 | THOMSON 近1年无新注册 |
| Hisense/TCL/Sony × IC-ISED | 0 条 | ISED API 不稳定 |
| IC/ISED × launch_warning | 0 条 | 近1年仅 2 条非电视类 |
| TÜV × launch_warning | 0 条 | description 无电视关键词 |
