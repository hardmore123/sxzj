## 一、模型代理与 AI 工具接入（`桌面\setting\`）

这一套脚本让 VSCode 的 Claude Code 和 DSH 都能用海信自研模型（聚好看 HiGPT / xinghai-ultra），是实习期间最高频使用的工具链。

| 脚本 | 用途 | 启动方式 |
|---|---|---|
| `anthropic_to_openai_proxy.fixed.py` | 核心代理：监听 8082，把 Anthropic/OpenAI 协议转成 HiGPT 的 OpenAI 格式 | 由启动脚本拉起 |
| `start-claude-hisense.ps1` | 一键后台启动代理并做健康检查 | `powershell -File start-claude-hisense.ps1` |
| `install-proxy-autostart.ps1` | 安装/查看/卸载看门狗自启动 | `-Status` 看状态、`-Remove` 卸载 |
| `hisense-proxy-watchdog.vbs` | 看门狗：每 60s 探测代理，挂了自动重启 | 随登录自启动（已安装） |
| `install-proxy-fix.ps1` | 修复代理流式 tool_calls 分片 bug | 一次性修复脚本 |
| `test_proxy_offline.py` | 离线 mock 网关测试（不依赖内网） | `python test_proxy_offline.py` |
| `verify_dsh_route.mjs` | 校验 DSH 的 llm-pi-ai 配置是否被接受 | `node verify_dsh_route.mjs` |

**核心价值**：免下载浏览器、复用本机 Edge 指纹、持久化 profile 保登录态，让企业自研模型无缝接入主流 AI 编程工具。

**详细文档**：`桌面\setting\README.md`（245 行，含所有踩坑与修复记录）
