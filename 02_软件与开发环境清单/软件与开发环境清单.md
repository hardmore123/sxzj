## 六、系统环境变量（开发相关）

```
PYTHONIOENCODING=utf-8                          # Python 输出编码，防乱码
OVERSEAS_PROXY=http://127.0.0.1:7877            # 海外爬取出海代理
OVERSEAS_USE_PROFILE=1                          # 持久化浏览器 profile
OVERSEAS_HEADLESS=true                          # 无头浏览器
HISENSE_DSH_KEY=local-proxy-placeholder         # DSH 接海信模型占位凭据
```

> 海外爬取的三个环境变量缺一不可：代理用于出海、profile 用于登录态、utf-8 防乱码。
