比对策略是**分字段、多层次容错**，目的是"同一个意思、写法不同"的情况尽量判一致，只有真正不同才报不一致。

## 五个字段各自的策略

### 1. 制造商 / 生产厂（`cmp_company`）

三步走：

1. **归一化**：全角→半角、统一大小写、去掉公司后缀噪声词（Co. / Ltd / Corp / Inc / Electronics / Technology / International / Group / Holdings 等 30+ 个词）、去掉标点和空格
2. **包含判断**：归一化后 A 包含 B 或 B 包含 A → 一致
3. **相似度**：以上都不满足，算 SequenceMatcher 相似度 ≥ 0.86 → 一致（标注"近似"）

**你截图里的例子**：

- 表格：`HOLLYLAND CO LTD` → 归一化去掉 `co`、`ltd` → `hollyland`
- 官网：`Hollyland (Xiamen) Technology Corp Ltd` → 去掉 `technology`、`corp`、`ltd`、括号内容 → `hollylandxiamen`
- `hollyland` 包含在 `hollylandxiamen` 里？不包含。但反过来 `hollylandxiamen` 包含 `hollyland` → **一致** ✓

### 2. 型号（`cmp_model`）

- 把表格/官网的型号各自切分成**型号集合**（按 `/,;、，；换行` 等分隔）
- 去掉括号里的品牌/备注、去掉 `series/系列` 等修饰词
- 归一化后比对：**有交集** → 一致（部分命中也算，会标注"网站未列 N 个"）
- 支持 **VDE 通配**：官网型号含 `*` 的编译成正则匹配
- 以上都不满足，逐对算相似度 ≥ 0.9 → 一致（标注"近似"）
- 都不匹配 → 不一致

### 3. 标准（`cmp_standard`）

- 用正则抽取标准号集合（EN IEC 62368-1:2020+A11 → `en62368-1:2020+a11`）
- 精确交集有 → 一致
- 精确没有，去掉年份/修订后的核心号（`en62368-1`）有交集 → 一致（标注"版本/年份不同"）
- 都没有 → 不一致

### 4. 证书状态（`cmp_status`）

- 映射到"有效/失效"两态（识别 valid/active/listed/有效 vs withdraw/expired/cancel/失效 等词）
- 同态 → 一致；不同 → 不一致

### 5. 特殊情况处理

| 场景                | 判定          | 说明                                           |
| :------------------ | :------------ | :--------------------------------------------- |
| 表格该字段空        | `表格未填`    | 不判不一致                                     |
| 官网没有该字段      | `网站无此项`  | 不判不一致（如 VDE 不返回标准、UL 不返回型号） |
| 查到但不匹配        | `不一致`      | 红字标注 + 附官网值                            |
| 证书号在官网找不到  | `官网未查到`  | 整行标黄                                       |
| 被网络拦截          | `被拦截`      | 可配置立即停止                                 |
| ENEC / 非有效证书号 | `未支持/跳过` | 标"人工核对"                                   |

## 总结一句话

**容错优先**：公司名去后缀做包含+相似度、型号切集合做交集+通配+近似、标准去年份做核心号匹配。只有归一化后确实对不上，才判不一致。宁可漏报（真不同没报出来）少一些，也不误报（同一个东西写法不同硬判不一致）。
