#### 四、通用公式约定

- 算术平均：`X̄ = Σxᵢ / n`

- 环比增长率：`R = (本期值 − 上期值) / 上期值 × 100%`

- 占比：`P = 部分值 / 总体值 × 100%`

- 命中率：`命中率 = 命中条数 / 触发总条数 × 100%`

- 采纳率：`采纳率 = 已采纳决策数 / 可采纳决策总数 × 100%`

- 准确率（人工抽检）：`准确率 = 抽检判定正确数 / 抽检总数 × 100%`

- 置信度：`Conf = P(结论为真 | 证据集)`（模型校准概率，0–100%）

- 百分点（pp）：用于差值表达，`↓0.8pp = 本期值 − 上期值 = −0.8 个百分点`

#### 五、标注约定

- 所有销量/份额/增长/价格/声量/预算等展示数值均为**示例数据（非真实抓取）**，公式按行业通用口径给出；示例验算中构造的输入一律标注"示例数据（非真实抓取）"。

## 1\. 运营总览（view\-overview）

### 1\. 产品竞争力指数

- **UI 位置**：运营总览 → 顶部 KPI 区 → 第 1 张卡「产品竞争力指数」

- **页面展示值**：87（副标：↑ 2 较上周；状态旗：领先）

- **业务定义**：本产品线在选定区域与统计周期内，相对主要竞品的综合竞争力评分（0–100），数值越高代表综合竞争地位越强。

- **计算公式**：`C = Σᵢ (wᵢ × sᵢ)`，其中 C 为竞争力指数；sᵢ 为第 i 个能力维度的归一化得分（0–100，维度如画质/音质/智能/游戏/设计/连接，取自 SPEC 归一化对比）；wᵢ 为第 i 维权重，且 Σwᵢ = 1。周环比 `ΔC = C_t − C_{t−1}`（页面"↑ 2"）。

- **数据来源**：SPEC 归一化对比表（维度得分 sᵢ）、能力权重配置表（wᵢ）、规格参数/评测/网评等原始爬取数据。

- **口径与边界说明**：页面展示值为单产品线均值，旗舰线 = 87（锁定口径锚点）。注意：竞品对阵分析页能力雷达图（chart\-radar，海信 U9N 六维 \[88,82,74,90,85,80\]）仅展示 SPEC 能力维度得分，等权均值 83\.17，与竞争力指数 87 **不是同一口径**，不得混用。权重配置未在 UI 展示。

- **示例验算**（python3 已算）：构造六维加权示例 s=\[92,88,90,85,80,78\]、w=\[0\.25,0\.20,0\.15,0\.20,0\.10,0\.10\] → 92×0\.25\+88×0\.20\+90×0\.15\+85×0\.20\+80×0\.10\+78×0\.10 = 86\.9 ≈ 87（取整），与页面 87 一致。输入为示例数据（非真实抓取）。

- **备注**：精确复算依赖权重配置表，属"待确认"项；雷达图为 SPEC 维度展示，不等同竞争力指数。

### 2\. 均价差 vs 竞品

- **UI 位置**：运营总览 → 顶部 KPI 区 → 第 2 张卡「均价差 vs 竞品」

- **页面展示值**：\-3\.2%（副标：↓ 0\.8pp；状态旗：关注）

- **业务定义**：我方指定产品线/品类在统计周期内的销量加权平均售价，相对竞品组合销量加权平均售价的差异百分比；负值表示我方均价低于竞品均价。

- **计算公式**：`D = (P̄_self − P̄_cmp) / P̄_cmp × 100%`；其中 `P̄_self = Σ(p_i·q_i) / Σq_i`（我方各渠道×型号组合的到手价 p\_i 按销量 q\_i 加权），`P̄_cmp` 为竞品组合同口径加权均价。周环比 `ΔD = D_t − D_{t−1} = −0.8pp`。

- **数据来源**：多渠道价格爬取表（AM 五渠道：型号、渠道、到手价、采集时间）、销量/份额数据表（加权 q\_i）。

- **口径与边界说明**：以到手价/成交价为准，采集窗口为统计周；竞品组合范围按对标设置。锁定口径锚点 \-3\.2%。

- **示例验算**（python3 已算）：设 P̄\_self = 1120 €、P̄\_cmp = 1157 € → \(1120−1157\)/1157 × 100% = −3\.20%，与页面 \-3\.2% 一致。输入为示例数据（非真实抓取）。

- **备注**：与价格监控页"渠道间价差"是不同指标（本指标是 vs 竞品组合均价差，彼处是渠道间价差超 8% 异常标注）。

### 3\. 网评健康度 / 负评率

- **UI 位置**：运营总览 → 顶部 KPI 区 → 第 3 张卡「网评健康度」（副标含负评率）

- **页面展示值**：4\.3（副标：负评率 11%；状态旗：健康）

- **业务定义**：统计周期内本产品线所有有效用户评论的平均星级评分（0–5）；负评率为 1–2 星评论占全部有效评论的比例。

- **计算公式**：`H = Σ(star_k × n_k) / N`，其中 star\_k ∈ \{1,2,3,4,5\}，n\_k 为 k 星评论条数，N = Σn\_k 为有效评论总数；负评率 `NEG = (n_1 + n_2) / N × 100%`。

- **数据来源**：网评爬取表（平台、型号、星级、评论内容、抓取时间）、评论去重表。

- **口径与边界说明**：有效评论=通过去重与机型匹配校验的评论；统计周期=本周。锁定口径锚点：4\.3 与 11% 必须自洽。

- **示例验算**（python3 已算）：N=1000，星级分布 n=\[640,200,50,60,50\]（5→1 星）→ H=\(5×640\+4×200\+3×50\+2×60\+1×50\)/1000 = 4\.32 ≈ 4\.3 ✓；NEG=\(60\+50\)/1000 = 11\.0% ✓。示例数据（非真实抓取）。

- **备注**：用户网评监测页另有"差评增速 \+45%（两周）"与"评价声量 1,240"，为不同指标，口径须分别说明。

### 4\. 待处置预警

- **UI 位置**：运营总览 → 顶部 KPI 区 → 第 4 张卡「待处置预警」

- **页面展示值**：3（副标：含 1 条高严重度；状态旗：待处理/警告边框）

- **业务定义**：当前处于"待处置"状态且归属当前角色负责的预警总数。

- **计算公式**：`W = W_high + W_med + W_low`，其中 W\_high / W\_med / W\_low 为按严重度（高/中/低）分级的有效待处置预警数。

- **数据来源**：预警表（预警 ID、严重度、状态、处置负责人、触发时间）。

- **口径与边界说明**：与预警聚合卡同口径（高·价格倒挂 1 \+ 中·新品认证 1 \+ 中·差评爆发 1）；锁定口径锚点 W=3。另有"近 7 天全部触发"口径（含已处置/已忽略的触发记录）计数不同，本卡仅计"待处置"。

- **示例验算**（python3 已算）：W = 1（高）\+ 2（中）\+ 0（低）= 3 ✓。

- **备注**：与预警聚合卡合计 3 互为校验；与预警中心页清单同口径。

### 5\. 市场机会点

- **UI 位置**：运营总览 → 顶部 KPI 区 → 第 5 张卡「市场机会点」

- **页面展示值**：2（副标：新增 1 条；状态旗：2）

- **数据来源**：机会点识别表（机会描述、发现时间、状态、来源模块）。

- **口径与边界说明**：示例演示数据（非真实抓取）。

- **示例验算**（python3 已算）：O = 1（存量）\+ 1（新增）= 2 ✓，与页面 2 一致。示例数据（非真实抓取）。

- **备注**：无。
