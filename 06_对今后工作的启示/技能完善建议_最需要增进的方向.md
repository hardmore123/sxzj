> 基于实习期间全部工作的系统复盘，分析当前能力结构中最需要完善增进的技能。

---

## 二、最需要完善的五个方向（按优先级排序）

### 🔴 优先级1：前端全栈能力（当前最大短板）

**为什么最需要**：
- 实习期间前端几乎完全依赖AI生成，自己只到"前后端初学"水平
- 电视产品运营AI平台的UI设计做了45KB文档，但**没有自己实现**
- 竞品对阵分析的前端（React+Ant Design）是训练营项目带的，不是独立开发的
- 后端能力已经很强，但**前后端无法独立闭环**会严重限制"一个人交付完整产品"的能力

**具体要补的**：
| 技能 | 学到什么程度 | 怎么学 |
|---|---|---|
| React 组件化 | 能独立写中等复杂度页面 | 把实习期间AI生成的前端代码逐行读懂、自己重写一遍 |
| 状态管理 | 理解Context/Zustand选型 | 分析CertAgent前端的状态管理方案 |
| 前端工程化 | Vite配置/构建/部署一条龙 | 用实习项目的前端做练手 |
| CSS布局 | Flex/Grid响应式 | 不用AI，手写竞品对阵分析页面 |

**最快路径**：把实习期间4个项目的前端代码全部自己重写一遍——有现成的后端和设计文档，只需补前端实现能力。

---

### 🔴 优先级2：系统化部署与云原生能力（从"踩坑学"到"系统学"）

**为什么需要**：
- 实习期间部署经验全靠踩坑积累——systemd缺HOME、nginx子路径、断电恢复、`.doc`卡死
- 整理出了"部署检查清单"，但这只覆盖了单机部署
- **没有Docker/K8s实践**——训练营学了Docker容器化笔记，但实际项目没用到
- 企业级部署（高可用/灰度/监控/告警）完全没接触

**具体要补的**：
| 技能 | 当前 | 目标 |
|---|---|---|
| Docker | 笔记层面 | 能把CertAgent和爬取项目容器化 |
| CI/CD | GitLab推送算手动 | 能写GitLab CI流水线自动构建部署 |
| 监控告警 | 无 | Prometheus+Grafana基础 |
| Nginx进阶 | 单机反代 | 负载均衡/SSL/限流 |

**最快路径**：先把实习期间的2个已上线项目Docker化，再写GitLab CI流水线。

---

### 🟡 优先级3：数据库与数据工程能力（从SQLite到生产级）

**为什么需要**：
- 实习项目全用SQLite——单机够用，但不支持并发写、不支持多实例
- 训练营学了PostgreSQL/Redis/Milvus，但**没有在真实项目中实践**
- 爬取项目14万行数据在SQLite里，如果数据量再大10倍就撑不住了
- 数据仓库/ETL/数仓建模完全没有接触

**具体要补的**：
| 技能 | 当前 | 目标 |
|---|---|---|
| PostgreSQL | 笔记层面 | 把爬取项目迁移到PostgreSQL |
| Redis | 笔记层面 | 做爬取任务队列/缓存 |
| 向量数据库 | 概念了解 | 给认证智能体加语义检索 |
| 数据建模 | 经验式 | 系统学范式/反范式/数仓分层 |

---

### 🟡 优先级4：算法与模型理解深度（从"会用"到"会调"）

**为什么需要**：
- 实习期间LLM使用方式是"给prompt拿结果"，对模型内部原理只到"层数问题""知识蒸馏"的笔记层面
- 没有做过模型微调——训练营有SFT微调数据笔记，但没实践
- 没有做过模型评测的系统方法——setting文件夹有评测报告但是手动对比
- **RAG vs 长上下文 vs 微调的选型判断**只停留在笔记，没有实测对比

**具体要补的**：
| 技能 | 当前 | 目标 |
|---|---|---|
| Prompt Engineering | 实践丰富但经验式 | 系统化（CoT/ReAct/结构化输出） |
| RAG | 知道弊端 | 搭一套RAG系统实测对比 |
| 模型微调 | 没做过 | 用LoRA微调一个小模型 |
| 模型评测 | 手动对比 | 建自动化评测pipeline |

---

### 🟢 优先级5：产品思维与需求工程（从"接需求做"到"定义需求"）

**为什么需要**：
- 实习期间是"接到需求→实现"，PRD是别人写的
- 电视产品运营AI平台做了UI设计但**功能边界是自己猜的**
- 竞品对阵分析的"归一化规则"是业务知识，缺乏从业务侧主动定义的能力
- 能力边界诚实是好事，但"定义能力边界"本身是产品能力

**具体要补的**：
- 需求拆解：把"做一个XX"拆成可验收的用户故事
- 优先级判断：MVP该做什么、不该做什么
- 用户视角：从"技术能做什么"转向"用户需要什么"

## 四、一句话总结

> 实习期间建立了**很强的AI应用架构设计能力和工程方法论**，这是核心竞争力。
> 但**前端全栈能力是最大短板**——后端能独立交付，前端完全依赖AI生成。
> **第二短板是系统化部署能力**——实战经验丰富但不系统（Docker/CI/CD/监控全缺）。
>
> 如果只能补一个技能：**补前端**——因为后端已经够强，补上前端就能独立交付完整产品。
> 如果能补两个：**补前端 + Docker/CI**——因为这是"从能跑到能稳定跑"的关键跨越。
